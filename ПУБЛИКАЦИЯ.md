# Публикация сайта: домен и Яндекс

Всё, что нужно сделать, чтобы сайт открывался по своему адресу и находился в Яндексе.

## 1. Домен

**Рекомендую: `arhitektura-lica.ru`** — проверено, свободен.

Название взято из авторской методики Татьяны Викторовны «Архитектура лица». Чем это хорошо:
это не «ещё один сайт косметолога», а собственное имя метода. Легко продиктовать по телефону,
легко запомнить, не привязано к району — если она переедет, домен останется верным.

**Альтернативы, тоже свободные** (проверял через whois Руцентра):

| Домен | Чем хорош | Чем хуже |
|---|---|---|
| `kosmetolog-vnukovo.ru` | Прямо говорит, кто и где — плюс для местного поиска | Привязывает к району навсегда |
| `vnukovo-kosmetolog.ru` | То же самое | То же самое |
| `lica-vnukovo.ru` | Короткий | Менее понятный |
| `estetika-vnukovo.ru` | Звучит мягче | Ещё одно «эстетика» |
| `tatyana-kosmetolog.ru` | Личный бренд | Имя встречается часто, легко спутать |

**Где покупать:** reg.ru, timeweb, beget, nic.ru. Цена на `.ru` — примерно 200–300 ₽ в год,
у Руцентра (nic.ru) — дороже, около 800 ₽. Домен оформляется на неё или на вас — как договоритесь,
но **владельцем лучше сделать Татьяну**, иначе она окажется заложницей исполнителя.

Домен `.рф` (`архитектура-лица.рф`) рассматривать можно, но смешанные домены хуже работают
в рекламе и письмах — люди путаются при наборе.

## 2. Где разместить сайт

### Вариант А. GitHub Pages — бесплатно, но за границей

Сайт уже там лежит, нужно только подключить домен.

**Плюсы:** бесплатно, ничего не нужно администрировать, HTTPS сам.
**Минусы:** серверы за рубежом — сайт может открываться медленнее, а формально это
противоречит требованию 152-ФЗ хранить персональные данные в России. Для сайта-визитки
с формой, которая **не отправляет данные на сервер**, риска почти нет, но знать об этом стоит.

**Шаги:**

1. В настройках домена у регистратора прописать DNS-записи:
   ```
   A     @    185.199.108.153
   A     @    185.199.109.153
   A     @    185.199.110.153
   A     @    185.199.111.153
   CNAME www  tokerjum-stack.github.io
   ```
2. В репозитории `tatyana-cosmetolog` создать файл `CNAME` (без расширения) с одной строкой:
   ```
   arhitektura-lica.ru
   ```
3. В настройках репозитория: **Settings → Pages → Custom domain** — вписать домен,
   дождаться проверки, включить галочку **Enforce HTTPS**.

⚠️ **Важно:** пока DNS не настроен, файл `CNAME` добавлять нельзя — GitHub начнёт
перенаправлять на несуществующий домен и текущая ссылка `tokerjum-stack.github.io/tatyana-cosmetolog/`
перестанет открываться. Порядок именно такой: сначала DNS, потом файл.

### Вариант Б. Российский хостинг — надёжнее для РФ

**Плюсы:** серверы в России, скорость для местных клиентов выше, 152-ФЗ соблюдён,
поддержка на русском, можно поставить почту на своём домене.
**Минусы:** стоит денег (от 150 ₽ в месяц), FTP и панель — вручную.

**Шаги:**

1. Купить хостинг с поддержкой PHP (не нужен, но обычно идёт в комплекте) и бесплатным SSL.
   Подойдут timeweb, beget, reg.ru — самый дешёвый тариф.
2. Привязать домен к хостингу: в панели хостинга добавить домен, затем прописать
   DNS-серверы хостинга у регистратора (или A-запись на IP хостинга).
3. Включить бесплатный SSL-сертификат (Let's Encrypt) — в панели это одна кнопка.
4. Загрузить содержимое архива
   `публикация/arhitektura-lica.ru.zip` в папку `public_html` (или `www`) и распаковать.
   В корне должен оказаться `index.html`, рядом папки `css`, `js`, `img`.
5. Проверить, что открывается `https://arhitektura-lica.ru/`.

**Готовый архив уже собран:** `C:\Users\toker\Сайт для подруге\tatyana-cosmetolog\публикация\arhitektura-lica.ru.zip`
— 27 файлов, 1,8 МБ, только то, что нужно на хостинге.

## 3. Яндекс.Вебмастер — чтобы сайт попал в поиск

1. Зайти на **https://webmaster.yandex.ru**, добавить сайт `https://arhitektura-lica.ru`.
2. Подтвердить права. Самый простой способ — метатег: Вебмастер даст строку вида
   `<meta name="yandex-verification" content="abc123...">`.
   Вставьте её в `index.html` — место уже подготовлено, там есть комментарий
   «ПОДТВЕРЖДЕНИЕ ПРАВ В ЯНДЕКС.ВЕБМАСТЕРЕ». Раскомментируйте и подставьте свой код.
3. После подтверждения: **Индексирование → Файлы Sitemap** → добавить
   `https://arhitektura-lica.ru/sitemap.xml`.
4. Там же: **Индексирование → Переобход страниц** → отправить главную.
5. Проверить `robots.txt` через инструмент **Инструменты → Анализ robots.txt**.
6. Включить **Мониторинг → Обход по счётчику Метрики**, когда счётчик заработает.

Первая индексация обычно занимает **от нескольких дней до двух недель**. Это нормально,
ускорять нечем — просто ждать.

## 4. Яндекс.Метрика — чтобы видеть посетителей

1. Создать счётчик на **https://metrika.yandex.ru** для домена `arhitektura-lica.ru`.
2. Включить опции: **Вебвизор**, **Карта скроллинга**, **Аналитика форм**, **Точный отказ**.
3. Скопировать номер счётчика (например, `12345678`).
4. В `index.html` внизу есть закомментированный блок «ЯНДЕКС.МЕТРИКА» — раскомментировать
   и заменить `12345678` на свой номер в двух местах.
5. Тот же номер вписать в `js/main.js` в переменную `CONFIG.metrikaId` — иначе не будут
   работать цели. Уже настроены две: `booking_send` (отправлена заявка) и `booking_error`.

**Зачем это нужно на практике:** Метрика покажет, с каких фраз приходят люди, на каком месте
бросают читать, нажимают ли на кнопку звонка. Без неё сайт — чёрный ящик.

## 5. Яндекс.Бизнес — часто важнее самого сайта

Для локальных услуг карточка организации на Картах даёт больше клиентов, чем сайт.
Люди ищут «косметолог рядом» и звонят прямо из карточки.

1. Зайти на **https://business.yandex.ru**, добавить организацию.
2. Заполнить: название, адрес (`Внуково, ул. 2-я Рейсовая, 25`), телефон, часы работы,
   категории («косметология», «массаж», «уход за лицом»).
3. **Ссылку на сайт указать ту же** — `https://arhitektura-lica.ru`.
4. Загрузить фотографии: кабинет, документы, работы.
5. **Название, адрес и телефон должны совпадать на сайте и в карточке символ в символ.**
   Это один из главных факторов ранжирования по гео: Яндекс сверяет данные и доверяет
   тем, у кого они одинаковые.

## 6. Что проверить после публикации

- [ ] `https://arhitektura-lica.ru/` открывается, замок в адресной строке есть (HTTPS)
- [ ] `http://` автоматически перенаправляется на `https://`
- [ ] Работают оба зеркала: и `arhitektura-lica.ru`, и `www.arhitektura-lica.ru`
- [ ] `https://arhitektura-lica.ru/robots.txt` и `/sitemap.xml` открываются
- [ ] На телефоне всё работает: меню, галерея, форма
- [ ] Форма готовит сообщение и телефон кликается
- [ ] Метрика считает визиты (проверить в реальном времени)
- [ ] Вебмастер показывает сайт подтверждённым
- [ ] Карточка в Яндекс.Бизнесе прошла модерацию

## 7. Чего я не сделала и почему

**Не купила домен** — покупка требует денег, паспортных данных и вашего согласия
с условиями регистратора. Это можете сделать только вы.

**Не добавила файл `CNAME`** — как объяснено выше, до настройки DNS он сломает
текущую рабочую ссылку.

**Не подключила Метрику и Вебмастер** — нужны номера счётчика и код подтверждения,
которые выдаются только после создания аккаунтов под вашим именем.

Всё остальное готово: метатеги, микроразметка, robots, sitemap и canonical
уже указывают на `arhitektura-lica.ru`.
